我目前在阿卜杜拉国王科技大学（KAUST）做博士后，主要做计算地震学，以及机器学习和波动方程的结合。

现在的工作主要围绕全波形反演（FWI）和地震成像。一方面写可微分的波动方程求解器，自己开发了 SWEEP，把各种波动方程的正演和反演放在一个统一的框架里；另一方面用隐式神经表示（INR）来表示速度模型，做多分辨率哈希编码、网络重参数化这些方向。

读博期间做得比较多的是地震数据处理里的深度学习，比如去噪、混采数据分离，还有海底节点（OBN）数据里多次波和横波泄漏的压制。另外我也一直在写 GPU 代码，做正演加速和大规模反演的高性能计算。

有问题欢迎发邮件给我。代码在 GitHub 上，论文可以看我的 Google Scholar。
