# geophyai.com

Personal academic website of **Shaowen Wang** — Postdoctoral Fellow in
Computational Geophysics at [KAUST](https://deepwave.kaust.edu.sa/).

🌐 **Live at [geophyai.com](https://geophyai.com)**

Research interests: differentiable wave-physics solvers, implicit neural
representations (INRs) for full-waveform inversion (FWI) and seismic imaging,
deep learning for seismic data processing, and high-performance computing.

## Build & deploy

Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme
and deployed to GitHub Pages via GitHub Actions (`main` → `gh-pages`).

Local preview with Docker:

```bash
docker compose up   # → http://localhost:8080
```
